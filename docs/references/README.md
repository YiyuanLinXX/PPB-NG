# PPBNG 资料归档规则

`source_register.tsv` 是项目使用过的厂商资料总账。已有本地资料只登记原始绝对路径、
大小和 SHA-256，不复制或修改旧资料目录。这样既保持旧资料只读，也能确认日后阅读的
是否仍是同一版本。

以后查询新资料时必须登记：设备、标题、厂商、文档版本/发布日期、官方 URL、访问
日期、本地状态、路径和 SHA-256。公开且允许下载的厂商 PDF 可保存到用户的统一资料
目录后登记；动态网页或许可不明确的内容保存 URL、访问日期、关键结论和必要的短摘录，
不把网页抓取物冒充厂商原始 PDF。需要账号、license、NDA 或包含序列号/密钥的资料不
复制进 workspace 或版本控制。

登记状态：

- `LOCAL_VERIFIED`：已找到本地文件并计算 SHA-256；
- `ONLINE_ONLY`：已使用官方在线来源，但尚无本地原文件；
- `MISSING_REQUIRED`：实现或硬件验收仍需要该资料；
- `SUPERSEDED`：保留旧记录，但另有明确的新版本。
